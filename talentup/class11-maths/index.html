What's different in Class 11

Built for a year with no board exam.

7′

The daily set

Four quick reviews, one new idea, one challenge and one "explain it back" — about seven minutes. Done daily, it covers the whole syllabus without cramming.

⟲

Visual playground

Every concept has something to move: drag a point, change a coefficient, rotate a shape. Understanding comes from the hands, not just the voice.

B/J

Boards or JEE, tagged

Every question is tagged by exam. Students preparing for JEE see the extra depth; students aiming at Boards aren't buried in it.

What's the same

Everything that works in Class 10.

  • Visual Learn animation before every topic
  • Teacher voice with every line of working on screen
  • From the Book worked problems and Ask AI "explain this step"
  • Mistake Book and weekly parent report
  • Parent holds the account; no ads; delete in-app
